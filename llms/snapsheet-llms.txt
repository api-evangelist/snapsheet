# Snapsheet

> Snapsheet is a cloud-based property & casualty (P&C) claims management platform for insurance carriers, MGAs, and TPAs. It combines no-code workflow configuration, intelligent automation, document management, virtual appraisals, claims payments, and analytics to run the full claims lifecycle. Snapsheet reports serving 170+ customers, including 16 of the top 20 P&C carriers, and processing 400M+ API calls monthly.

This file is generated by the API Evangelist enrichment pipeline from the public Snapsheet website. Snapsheet exposes open APIs and webhooks to its customers and partners, but publishes no public developer portal, API reference, or OpenAPI specification; API access is arranged through the sales/partner channel.
